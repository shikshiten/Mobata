ARCHITECTURAL ADVANTAGES

Engineered For Real Networks.

Built to survive connection drops, strict firewalls, and aggressive Telegram rate limits.

[TCP]

Anti-Throttling Protocol

Employs ConnectionTcpObfuscated to prevent restrictive Wi-Fi routers and ISP deep-packet inspection (DPI) from resetting connections.

[STREAM]

In-App Video Streaming

Flags every uploaded video with supports_streaming=True so videos play immediately inside Telegram channels without full download.

[AUTO]

Self-Healing FloodWait

Automatically intercepts Telegram rate-limit challenges, sleeps for the exact server-requested seconds, and resumes without crashing.

[LOCK]

Instance Protection

Integrated process locking stops overlapping instances, completely eliminating the "Server replied with a wrong session ID" error.

[QUEUE]

Smart Priority Sorting

Prioritizes small photos first so thousands of files upload rapidly, ensuring continuous progress before tackling massive 4K video files.

[SYNC]

Zero-Loss Persistence

Records uploaded paths to uploaded_history.txt after every success. Power cuts or laptop restarts won't re-upload duplicates.

DEPLOYMENT MATRIX

Get Started in 3 Minutes.

Choose your preferred operating environment.

01

Clone Repository & Install Requirements

Requires Python 3.9 or higher (compatible with Windows, macOS, Linux).

git clone https://github.com/shikshiten/Mobata.git
cd Mobata
pip install -r requirements.txt
02

Obtain Free Telegram API Credentials

Visit my.telegram.org, log in with your Telegram number, click API Development Tools, and copy your API ID and API HASH.

03

Configure Environment (.env)

Copy .env.example to .env and insert your details:

TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
TELEGRAM_PHONE=+1234567890
TELEGRAM_CHANNEL_ID=-1001234567890
UPLOAD_FOLDER=C:\Pictures\Upload
04

Start Uploading

Double-click run_uploader.bat on Windows, or run in terminal:

python uploader.py
01

Deploy on Docker / TrueNAS / Unraid

Mount your local photo volume and run continuously in the background.

docker compose up -d
docker compose logs -f
01

Deploy on Cloud Workers (Koyeb / Heroku / VPS)

The repository includes a Procfile for seamless background worker deployment:

worker: python uploader.py
01

Automate Camera & Cloud Dumps

Trigger uploads whenever new media arrives via Google Drive, Nextcloud, or Webhooks:

[Google Drive / Camera Sync] ➔ [n8n Trigger] ➔ [Mobata Queue] ➔ [Telegram Channel]
