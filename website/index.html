CORE ARCHITECTURE

Engineered for Reliability.

Every mechanism built to withstand real-world network conditions.

[TCP]

Anti-Throttling Protocol

Employs ConnectionTcpObfuscated to prevent restrictive Wi-Fi routers and ISP deep-packet inspection (DPI) from dropping connections.

[STREAM]

In-App Streaming

Flags every uploaded video with supports_streaming=True so videos play immediately inside Telegram channels without full download.

[WAIT]

Self-Healing FloodWait

Dynamically intercepts Telegram rate-limit challenges, sleeps for the exact server-requested seconds, and resumes automatically without crashing.

[LOCK]

Instance Protection

Built-in process locking stops overlapping instances, completely eliminating the "Server replied with a wrong session ID" error.

DEPLOYMENT MATRIX

Setup in Three Minutes.

Choose your target environment.

01

Clone and Install Dependencies

Requires Python 3.9 or higher.

git clone https://github.com/shikshiten/Mobata.git
cd Mobata
pip install -r requirements.txt
02

Configure Credentials (.env)

Obtain your API ID and API HASH from my.telegram.org.

TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
TELEGRAM_PHONE=+1234567890
TELEGRAM_CHANNEL_ID=-1001234567890
UPLOAD_FOLDER=C:\Photos\Upload
03

Launch Uploader

Double-click run_uploader.bat on Windows, or execute via terminal:

python uploader.py
01

Run Headless Container

Mount your local photo volume and run continuously in the background.

docker compose up -d
docker compose logs -f
01

Deploy on Cloud Workers (Koyeb / Heroku)

Repository includes a pre-configured Procfile for background workers:

worker: python uploader.py
01

Automate Camera & Cloud Dumps

Trigger uploads whenever new media arrives via Google Drive, Nextcloud, or Webhooks:

[Google Drive / Camera Sync] ➔ [n8n Trigger] ➔ [Mobata Queue] ➔ [Telegram Channel]
