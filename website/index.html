2 GB – 4 GB Unlocked

Powered by native Telegram MTProto (Telethon User API). Eliminates the 50 MB bot barrier so you can upload full 4K videos without compression.

🔄

Zero-Loss Auto Resume

Real-time persistent state tracking. If power cuts or your Wi-Fi disconnects, Mobata picks up at the exact file where it stopped without duplicating messages.

⚡

Hardware Acceleration

Integrates compiled C cryptg AES-NI hardware encryption, delivering 20x to 80x faster uploads than standard pure-Python software encoders.

Anti-Throttling Protocol

Uses ConnectionTcpObfuscated to bypass restrictive network firewalls and deep-packet inspection (DPI) that cause WinError 64 drops.

In-App Video Streaming

Automatically flags uploaded videos with supports_streaming=True so they play instantly inside Telegram channels without waiting to download.

🛡️

Self-Healing Rate Limits

Catches Telegram's FloodWaitError dynamically, pauses safely for the required duration, and resumes automatically without crashing.

Get Started in 3 Minutes

Choose your preferred setup method below.

1

Clone Repository & Install Dependencies

Ensure you have Python 3.9+ installed on Windows, macOS, or Linux.

git clone https://github.com/shikshiten/Mobata.git
cd Mobata
pip install -r requirements.txt
2

Get Telegram API Credentials

Visit my.telegram.org, log in, open API Development Tools, and copy your API ID and API HASH.

3

Configure Environment (.env)

Copy .env.example to .env and insert your details:

TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=your_api_hash_here
TELEGRAM_PHONE=+1234567890
TELEGRAM_CHANNEL_ID=-1001234567890
UPLOAD_FOLDER=C:\Pictures\Upload
4

Run the Uploader

Double-click run_uploader.bat on Windows or run:

python uploader.py

Deploy Mobata on TrueNAS, Unraid, Synology, or any local Docker engine.

docker compose up -d
docker compose logs -f

Your media folder is mounted as a volume inside the container for continuous uploads.

Deploy on Koyeb / Heroku / Linux VPS

Mobata includes a ready-to-use Procfile for background worker deployment:

worker: python uploader.py

Set your environment variables in Koyeb/Heroku dashboard and trigger the deployment!

Automate with n8n / Webhooks

Automatically upload to Telegram whenever new photos arrive in Google Drive or Nextcloud:

[Google Drive / Camera Sync] ➔ [n8n Trigger Node] ➔ [Save to Folder] ➔ [Mobata Uploads to Telegram Channel]
