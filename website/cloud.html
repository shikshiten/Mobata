SERVERLESS WORKERS & AUTOMATION

Cloud & Automation Setup

Run Mobata as a background worker on Koyeb, Heroku, Hetzner, or integrate automated media sync pipelines with n8n.

01
Koyeb / Heroku Background Worker

The repository includes a Procfile configured for headless background process execution:

worker: python uploader.py

Deployment Steps:

  1. Fork or connect your GitHub repository to Koyeb or Heroku.
  2. Add your environment variables (TELEGRAM_API_ID, TELEGRAM_API_HASH, etc.) in the dashboard settings.
  3. Scale the worker dyno/process to 1.
  4. For cloud storage, mount an Amazon S3 bucket, Google Cloud Storage, or SFTP directory to UPLOAD_FOLDER.
02
Linux VPS (Ubuntu / Debian systemd Service)

To keep Mobata running automatically on server boot across system reboots, create a systemd daemon unit:

# Save to: /etc/systemd/system/mobata.service
[Unit]
Description=Mobata Automated Telegram Media Uploader
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/mobata
ExecStart=/opt/mobata/venv/bin/python uploader.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
# Enable and start the service:
sudo systemctl daemon-reload
sudo systemctl enable mobata
sudo systemctl start mobata

# Inspect live upload stream:
sudo journalctl -u mobata -f
