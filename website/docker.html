Docker & NAS Setup

Run Mobata headlessly on home servers, TrueNAS SCALE, Unraid, Synology, or Ubuntu VPS with volume persistence.

01
Docker Compose Configuration

Mobata includes a production-ready docker-compose.yml file with volume mounts for media and session caching:

version: '3.8'

services:
  mobata:
    build: .
    container_name: mobata_uploader
    restart: unless-stopped
    env_file:
      - .env
    volumes:
      # Mount your local photos/videos directory into the container
      - /path/to/your/media:/app/media:ro
      # Persist session & uploaded history on host storage
      - ./data:/app/data
02
Initial Session Login (Interactive Mode)

Telegram authentication requires entering a verification SMS/Telegram code once. Run the container interactively for the first launch:

# Build and run interactively for one-time code entry:
docker compose run --rm mobata python uploader.py

Once your session is generated in telethon_upload_session.session, it is stored in the mounted volume and never prompts again.

03
Start 24/7 Background Daemon

Now launch the container in detached background mode:

# Start in detached background mode
docker compose up -d

# View live upload telemetry and progress:
docker compose logs -f
04
Synology & Unraid Native Templates

For Unraid or Synology Container Manager, configure the container with:

  • Network Type: Bridge or Host
  • Volume Path 1: /mnt/user/photos ➔ /app/media (Read-Only)
  • Volume Path 2: /mnt/user/appdata/mobata ➔ /app/data (Read-Write)
