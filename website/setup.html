LOCAL WORKSTATION DEPLOYMENT

Local Machine Setup

Deploy Mobata directly on your Windows PC, Mac, or Linux desktop for maximum upload speed and zero hosting fees.

01
Prerequisites & Repository Clone

Ensure you have Python 3.9+ installed. Open your command prompt, Terminal, or PowerShell and clone the official repository:

# Clone Mobata repository
git clone https://github.com/shikshiten/Mobata.git
cd Mobata

# Create a clean virtual environment (recommended)
python -m venv venv
# Windows: venv\Scripts\activate
# macOS/Linux: source venv/bin/activate

# Install native dependencies and C-accelerated MTProto cryptg
pip install -r requirements.txt
02
Get Free Telegram API Credentials

Telegram provides free personal MTProto API credentials for all user accounts. Unlike bot tokens that cap uploads at 50 MB, personal API tokens allow up to 4 GB per file:

  1. Log in with your Telegram phone number at my.telegram.org.
  2. Click on "API Development Tools".
  3. Enter an App title (e.g. Mobata Uploader) and a short name.
  4. Copy your unique api_id (integer) and api_hash (hex string).
03
Configure Environment Variables

Copy .env.example to .env in the project folder and insert your credentials. All credentials remain 100% local on your machine:

TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef
TELEGRAM_PHONE=+1234567890
TELEGRAM_CHANNEL_ID=-1001234567890
UPLOAD_FOLDER=C:\Users\YourName\Pictures\Upload
04
Execute Uploader

On first run, Telegram will send a verification code to your official Telegram app. Enter the code in the terminal to authorize the session:

# Run directly:
python uploader.py

# Or on Windows, double-click:
run_uploader.bat
05
Autonomous Resume & Zero Duplicates

Mobata records every uploaded file immediately into uploaded_history.txt. You can press Ctrl + C at any time, turn off your laptop, or switch Wi-Fi networks. Running the script again instantly skips all finished items and resumes from the exact next item.
